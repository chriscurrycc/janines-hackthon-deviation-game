# 文档

同样的三张图（技术架构 / 角色交互 / 房间状态），按读者分两份：

| 文档 | 读者 | 风格 |
| --- | --- | --- |
| [PRODUCT.md](./PRODUCT.md) | 🧩 产品 / 非技术 | 偏产品：讲玩家体验与产品价值，不涉及端口、消息名等细节 |
| [ARCHITECTURE.md](./ARCHITECTURE.md) | ⚙️ 工程 | 偏技术：讲服务拆分、WebSocket 消息、房间内存状态等 |
| [TECH-NOTES.md](./TECH-NOTES.md) | 🔬 工程 | 技术细节深挖：某个点具体怎么实现（按需追加，如「笔迹同步」） |

> 图用 [Mermaid](https://mermaid.js.org/) 绘制，GitHub 可直接渲染。
